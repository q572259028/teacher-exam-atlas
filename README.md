# 师考雷达

2026 年杭州、广州、深圳信息技术教师编制岗位信息站：[在线访问](https://q572259028.github.io/teacher-exam-atlas/)。

## 内容口径

- 页面只展示人工核实且明确标记 `workCity` 为杭州、广州或深圳的岗位；“信息技术、信息科技、计算机、人工智能”属关注学科。考试地点不参与城市筛选。
- 每条岗位只有一个官方原文入口，卡片直接列出任职地点、考场、计划人数、报名截止、考试安排与资格要点。学校存在多个校区而岗位表未明确任职校区时，明确提示继续核实。
- 已结束岗位保留作往期参考，报名中状态同时依据公告截止日判断。计划招聘人数不等于最终录用人数。
- 同一岗位、同一批次的官方实考人数与最终录用人数不齐全时，通过比例保持空白。没有官方确定的未来批次计划时不推测日期。

## 数据更新

`.github/workflows/update-and-deploy.yml` 计划在北京时间每小时第 17 分钟巡检三个官方栏目，并部署 GitHub Pages。GitHub Actions 调度与官网响应可能延迟。自动巡检只发现招聘公告链接，不读取复杂附件、不自动断言学科或工作地点；核实后在 `data/curated.json` 增加岗位，再运行 `scripts/update.py` 更新 `data/publications.json`。巡检失败时公开状态，历史数据保留。

```bash
python3 scripts/update.py
python3 -m http.server 8000
```

本地打开 `http://localhost:8000`。直接双击 HTML 无法加载 JSON。

## 数据文件

- `data/sources.json`：杭州、广州、深圳的官方公告栏目。
- `data/curated.json`：人工核对的岗位与原文链接。
- `data/publications.json`：网站读取的合并数据，由巡检脚本生成。

新增岗位须核对官方公告及岗位表；不要把报名人数当作实考人数，不要把考试地点或单位联系地址当作岗位实际工作地点。
