# 师考雷达

面向 2026 年中国事业单位教师招聘的静态信息站。它提供官方栏目导航、每小时公告链接巡检、人工核实的公告摘要，以及可追溯的招录统计结构。

## 当前覆盖

已核验并接入北京、上海、湖南、甘肃四个官方栏目。站点**不声称全国完整覆盖**。`data/sources.json` 可继续增加官方栏目；自动发现的链接只显示标题与来源，详细报考信息须对照官方原文和附件核实。

当前人工核实样例见 `data/curated.json`。各条公告明确区分考场、单位联系地址、实际工作地点。`plannedHires` 是计划招聘人数，不是最终录用人数。

## 更新机制

`.github/workflows/update-and-deploy.yml` 在 UTC 每小时第 17 分钟运行（北京时间每小时第 17 分钟），读取官方栏目并更新 `data/publications.json`，然后部署 GitHub Pages。GitHub Actions 调度及政府网站响应可能延迟；页面展示实际巡检时间和失败状态。源站不可访问时保留历史链接，不冒充最新抓取结果。

脚本只使用 Python 标准库：

```bash
python3 scripts/update.py
```

本地预览：

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000`。直接双击 `index.html` 会受浏览器本地文件读取限制，无法加载 JSON。

## 发布到 GitHub Pages

1. 将本目录作为独立 Git 仓库推送到 GitHub，默认分支设为 `main`。
2. 仓库 `Settings → Pages → Build and deployment` 选择 `GitHub Actions`。
3. 在 `Actions` 页手动运行一次 **Update official links and deploy**，随后等待 Pages 地址生成。
4. 若组织策略限制 `GITHUB_TOKEN` 写入，请在仓库设置中允许 Actions 读写仓库内容。

公开仓库的站点地址通常是 `https://<用户名>.github.io/<仓库名>/`。GitHub Pages 静态托管无需服务器或数据库。

## 数据规则

- **官方来源**：政府人社部门、教育部门或事业单位官方页面；添加来源时核查域名、栏目内容和发布时间。
- **公告链接**：自动抓取仅识别官网栏目中的招聘相关标题，不自动断定教师编制属性或提取复杂资格条件。
- **历史通过率**：仅在同一地区、岗位和招聘批次同时有官方实考人数与最终录用人数时计算 `最终录用人数 / 实考人数`。报名人数与实考人数不同；计划数与录用人数不同。缺数据时留空。
- **计划**：只收录官方政策或明确计划，不按往年时间推测未来考试。
- **时间与地点**：考场以准考证或考务通知为准，工作地点以岗位表及招聘单位确认为准，不能用网站页脚地址代替。

## 贡献信息

优先在 `data/curated.json` 补充已核验的招聘信息。每项须有官方原文链接；新增历史统计需含明确的 `examTakers`、`finalHires` 和对应官方链接。不要提交考生个人信息。可以通过 Pull Request 更新来源与更正信息。

## 局限

当前自动巡检仅覆盖四个已接入栏目，无法保证捕获各地教育局、区县政府及学校官网的全部招聘；部分政府网站可能限制自动读取或使用动态页面。公告内容、附件、补充通知与最终名单仍应以官网为准。
