# 师考雷达

[在线访问](https://q572259028.github.io/teacher-exam-atlas/)：面向 2027 届毕业生的杭州、广州、深圳信息技术教师编制岗位清单。

## 展示口径

网站只展示经过人工核对、明确允许 2027 届毕业生报考、实际工作城市为杭州/广州/深圳、学科为信息技术相关，且报名尚未截止或即将开始的岗位。每条记录在 `data/curated.json` 中须标注 `eligibleCohorts`，包含 `"2027"`，并写明报名截止日期。2025 年招聘 2026 届的公告和所有已结束批次均不进入页面。缺少符合条件的岗位时显示空状态，不用往期岗位充数。

岗位卡片区分学校实际工作地点与考试考场；多校区岗位若未明确任职校区，必须注明待核。计划招聘人数不能当作最终录用人数，报名人数不能当作实考人数。未来报名时间和招录比例没有可靠官方数据时不推测。

## 更新

`.github/workflows/update-and-deploy.yml` 计划在北京时间每小时第 17 分钟巡检官方栏目并部署 GitHub Pages。GitHub Actions 和官方站点可能延迟。巡检只发现招聘公告标题与链接，候选线索只保留最近 21 天，不能从附件自动确认毕业届别、学科和工作地点；核实后才能写入 `data/curated.json`。网站展示最近巡检时间和每个来源的可访问状态，巡检成功不等于有可报岗位。

本地运行：

```bash
python3 scripts/update.py
python3 -m http.server 8000
```

打开 `http://localhost:8000`。直接双击 HTML 无法加载 JSON。

## 数据文件

- `data/sources.json`：官方公告栏目，目前包括杭州、广州、南沙区和深圳。
- `data/curated.json`：已核实且符合上述展示口径的岗位。
- `data/publications.json`：网站读取的巡检结果，由脚本生成。
